# PostgreSQL DBA Project

This is an end-to-end PostgreSQL database administration project that I built 
using real-world public healthcare data from the Centers for Medicare & Medicaid 
Services (CMS). In this project I demonstrate my practical DBA skills across 
schema design, data loading, performance optimization, operations, security, 
and compliance.

## Project Overview

I used the **CMS Medicare Physician & Other Practitioners** dataset 
(9.6 million service records, 1.17 million unique providers) to simulate a 
production healthcare analytics database workload.

## Dataset

- **Source:** CMS Medicare Physician & Other Practitioners by Provider and Service
- **Year:** 2023
- **Records:** 9,660,647 service rows | 1,175,281 unique providers
- **Size:** ~3 GB raw CSV
